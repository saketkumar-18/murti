How it works

A 3D-convolution VAE compresses 32³ occupancy grids into 8³ latents; a classifier-free-guided diffusion model generates latents from your prompt; marching cubes turns the result into a mesh. All inference runs locally via ONNX Runtime WebAssembly — nothing is uploaded.
